# Rinha das Pseudociências

Jogo de luta 2D no estilo Street Fighter II em que os picaretas da saúde brigam entre si. Faz parte da série **Jogos e sátiras** do BACCHI LAB.

**Versão piloto.** Quatro lutadores, quatro cenários animados, tela título, modos Arcade, Versus e Treino.

| Lutador | Arquétipo | Cenário |
|---|---|---|
| Mestre Diluídio | Homeopata | Botica Homeopática |
| Coach Vibratto | Coach quântico | Palco do Seminário |
| Dona Clorofila | Vendedora de detox | Feira Detox na Orla |
| Dra. Evidência | Cientista (desbloqueável) | Laboratório da Universidade |

Os lutadores são arquétipos fictícios. Cada especial vem com a falácia por trás, e a tela de resultado traz o "Na vida real".

## Como jogar

Abra `index.html` no navegador, ou use a versão hospedada no GitHub Pages. Funciona no computador (teclado) e no celular (controles de toque).

Teclado no modo Arcade: mover e pular com `WASD` ou setas, soco `J`, chute `K`, especial `L`, super `I`, pausa `Esc`.

## Estrutura

O jogo é um arquivo único (`index.html`), com sprites, cenários e a biblioteca de QR code embutidos. Fora isso, só as fontes do Google Fonts.

Para instalar como app: `manifest.webmanifest`, `sw.js` (abre offline depois da primeira visita) e os ícones `icon-192.png`, `icon-512.png` e `apple-touch-icon.png`.

No menu: botão **← BACCHI LAB** (volta ao hub), **Instalar** e **QR code** (do endereço do jogo, para projetar em aula).
